Questions

Does Relay work with monorepos? +

Yes. Point each app at its folder and Relay builds only what changed.

Which hosts are supported? +

GitHub and GitLab today, with Bitbucket in beta.

Can previews use our own domain? +

On Pro and Enterprise, previews can live under a subdomain you own.

How is usage billed? +

Per active member each month; previews themselves are not metered on Pro.
